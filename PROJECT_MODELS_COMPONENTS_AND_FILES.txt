====================================================================================================

1. EXECUTIVE OVERVIEW
----------------------------------------------------------------------------------------------------
Project Name       : QuantumVision
Primary Domain     : Disaster Management, Early Warning, 3D Digital Twin & Evacuation Navigation
Geographic Scope   : Srikakulam District & Coastal Corridor of Andhra Pradesh, India
Key Hazards Covered: Riverine Flood Inundation (Nagavali & Vamsadhara basins), Flash Floods,
                     Heavy Monsoonal Rainfall, Cyclone & Coastal Storm Surge
Architecture Type  : Decoupled Full-Stack Architecture (FastAPI REST Backend + Vite React 3D HUD)
Core Paradigms     : Classical Machine Learning, Quantum-Inspired Optimization (QUBO & QML),
                     3D Geospatial Digital Twin, Real-Time Sensor Telemetry, and Dynamic Routing


====================================================================================================
2. MAJOR COMPONENTS USED IN SYSTEM IMPLEMENTATION
====================================================================================================

2.1 BACKEND ENGINE & SERVICES
----------------------------------------------------------------------------------------------------
- Framework        : FastAPI (v0.100+) with Uvicorn ASGI Server
- Language & Runtime: Python 3.12 (64-bit)
- Database         : SQLite 3 with SQLAlchemy ORM (v2.0+) and Alembic-ready schema definitions
- Schema Validation: Pydantic v2 (Strict type checking, request/response models, custom validators)
- Authentication   : Python-Jose (JWT cryptographic tokens), Passlib with Bcrypt password hashing
- Real-Time Comms  : WebSocket endpoint (`/ws/telemetry`) for streaming sensor updates & simulation state
- Core Services (22 Services Implemented):
  * `FloodPredictionService`      : Coordinates RF and XGBoost inferences on multi-source features
  * `RainfallForecastingService` : Leak-free chronological 24h precipitation forecasting
  * `RoutingService`             : Dynamic A* and Dijkstra pathfinding with flood-hazard penalty weights
  * `SimulationService`          : Multi-parameter hydraulic what-if disaster simulation engine
  * `DigitalTwinService`         : Harmonizes 3D spatial boundaries, inundation layers, road network & shelters
  * `QuantumService`             : Evaluates PennyLane VQC & QNN circuits and QUBO route/facility matrices
  * `FacilityService`            : Capacity monitoring and distance-ranked shelter/hospital matching
  * `HospitalService`            : Hospital bed availability, trauma tier tracking, and facility triage
  * `ShelterService`             : Evacuation shelter occupancy, food/water supply days, elevation safety
  * `RiskService`                : Composite multi-hazard risk categorization (Low, Moderate, High, Severe)
  * `NavigationService`          : Turn-by-turn waypoint generation for evacuation corridors
  * `EmergencyService`           : SOS alert dispatch, responder assignment, and civilian safety guidance
  * `DisasterService`            : Historical disaster cataloging, impact zoning, and damage assessment
  * `DatasetService`             : Multi-format geospatial dataset ingestion, validation, and metadata indexing
  * `LocationService`            : Andhra Pradesh district spatial hierarchy, bounding box validation
  * `VisualizationService`       : Raster/vector layer styling and dynamic heatmap matrix generation
  * `WeatherService`             : Open-Meteo ERA5 / NWP hourly atmospheric sync and station telemetry
  * `ReportsService`             : Automated post-disaster PDF/JSON situational assessment reports
  * `AuthService`                : User registration, role-based access control (Admin, Responder, Citizen)
  * `PredictionService`          : Generic composite risk scoring across spatial telemetry points

2.3 MACHINE LEARNING & EXPLAINABLE AI (XAI)
----------------------------------------------------------------------------------------------------
- Core Libraries   : Scikit-Learn (v1.3+), XGBoost (v2.0+), NumPy, Pandas, SciPy, Joblib
- Preprocessing    : Feature scaling (StandardScaler, MinMaxScaler to [-pi, pi]), Outlier clipping,

                     Rolling precipitation accumulation (3h, 6h, 12h, 24h, 3d, 7d, 14d)

- QUBO Engine      : Quadratic Unconstrained Binary Optimization formulation for graph-based path
                     search and facility allocation solved using Classical Simulated Annealing heuristics

MODEL 7: VARIATIONAL QUANTUM CLASSIFIER (VQC)
----------------------------------------------------------------------------------------------------
- File Path        : ml/artifacts/quantum/vqc_weights.npy
                     (Mirror in ml/models/vqc_weights.npy)
- Format           : NumPy N-Dimensional Binary Weights Array (.npy)
- Circuit Spec     : 4 Qubits, 2 Entangled Layers, 24 Parameterized Rotational Weights
- Simulator        : PennyLane `default.qubit` statevector simulator
- Encoding Method  : AngleEmbedding on 4 dominant features mapped into [-\pi, \pi]:
                     1. `sar_vv_db`
                     2. `sar_temporal_diff_db`
                     3. `elevation_m`
                     4. `rainfall_accum_24h_mm`
- Variational Gates: Parameterized `qml.Rot(\phi, \theta, \omega)` on all 4 wires followed by
                     periodic circular CNOT entangling gates
- Measurement      : Expectation value of Pauli-Z operator `qml.expval(qml.PauliZ(0))` mapped to [0, 1]
- Test Sample Count: 300 Identical Held-Out Srikakulam Test Samples
- Validated Metrics:
  * Accuracy       : 91.67%
  * Precision      : 62.75% (Flood Class 1)
  * Recall         : 84.21% (Flood Class 1)
  * F1-Score       : 71.91% (Flood Class 1)

MODEL 11: QUBO EVACUATION ROUTE OPTIMIZATION ENGINE
----------------------------------------------------------------------------------------------------
- Implementation   : `backend/app/services/quantum_service.py` & `quantum/route_optimization.py`
- Mathematical Form: Quadratic Unconstrained Binary Optimization:  min  x^T * Q * x
                     Subject to binary flow conservation constraints:
                     - Variable x_i = 1 if road segment i is selected in evacuation path
                     - Matrix Q penalizes distance, flood water level, bottleneck congestion, and road cutoffs
- Solver Algorithm : Classical Simulated Annealing with exponential cooling schedule
- Baseline Compare : Side-by-side benchmark against Classical Dijkstra and A* algorithms
